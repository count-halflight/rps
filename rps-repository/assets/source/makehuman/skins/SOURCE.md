# MakeHuman young Asian female skin

The original files in `young_asian_female/` were extracted without modification
from the MakeHuman II CC0 system asset pack on 2026-10-11:

https://github.com/Makehuman-2/MH2_Asset_Repository_CCO/releases/download/CC0/mh_system_CC0.zip

Archive member paths:

- `skins/young_asian_female/young_asian_female.mhmat`
- `skins/young_asian_female/young_lightskinned_female_diffuse3.png`
- `skins/young_asian_female/young_asian_female.thumb`

The diffuse is an original 2048 × 2048 RGB PNG for the standard MakeHuman body
UV layout. It contains the authored skin color and facial/body surface detail;
it is not a newly synthesized procedural texture. The system material names it
`young_asian_female` and tags it `young`, `asian`, `female`.

The material's original diffuse multiplier is `(1.0, 0.95, 0.85)`. Load the image
as sRGB and preserve the original base mesh UVs. Reapplying the previous dark
uniform skin color as a multiplier would alter and darken the original image.
The source supplies no normal, roughness or trained-athlete-specific map.

The `.mhmat` states: “This asset was explicitly released as CC0 in september
2020.” It lists copyright holders Data Collection AB, Joel Palmius and Jonas
Hauquier, each dated 2020. It does not identify a separate individual texture
artist. The pack's `README` says:

> The original vintage Makehuman system assets
> All of these assets are CC0.

The publishing repository's README also identifies all assets in its packs as
CC0. An unchanged copy of that repository's license is saved as `CC0-1.0.txt`.
