# Original Trinity character designs

The costumes, hair geometry, facial expression morphs, weapon meshes and animation code in Trinity: Afterlight are original work created for this project and distributed under the project's MIT license. The seamless leather, rib knit and hair surface maps are original procedural artwork generated by `scripts/build_echo_surfaces.py`; they contain no stock imagery.

The underlying human anatomy, skeleton and demographic morph sources are the CC0 MakeHuman assets documented in [MakeHuman-CC0.md](MakeHuman-CC0.md). No third-party characters, costumes or likenesses were used.
