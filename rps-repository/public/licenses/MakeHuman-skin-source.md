# MakeHuman skin source

The Echo source assets include the original MakeHuman system
`young_asian_female` skin material and its
`young_lightskinned_female_diffuse3.png` diffuse image, obtained from the
MakeHuman II CC0 system asset pack:

https://github.com/Makehuman-2/MH2_Asset_Repository_CCO/releases/download/CC0/mh_system_CC0.zip

The source diffuse is a 2048 × 2048 RGB image for the standard MakeHuman body
UV layout. It is preserved unchanged under
`assets/source/makehuman/skins/young_asian_female/`; any resized or embedded
game version is derived from that original.

The supplied `young_asian_female.mhmat` explicitly states that the asset was
released under CC0 in September 2020. Its listed copyright holders at that
release were Data Collection AB, Joel Palmius and Jonas Hauquier, each dated
2020. No separate individual texture artist is credited in the supplied
material. The archive's README states that all included assets are CC0, and the
publishing repository separately identifies its packs as CC0.
